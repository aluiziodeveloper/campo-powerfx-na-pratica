# Cartão de leitura de fórmulas

*Material de apoio do Capítulo 6. Uma página, para imprimir e deixar ao lado do teclado. Seis passos para atacar qualquer fórmula que você não escreveu.*

```
 1. ONDE ELA MORA?      Propriedade de dados ou de comportamento?
                        Só a segunda tem sequência e ordem.

 2. QUAL É O CONTORNO?  Qual é a função mais externa,
                        e quantos argumentos ela recebe?

 3. DE DENTRO PARA FORA Numere os níveis de parêntese.
                        Comece pelo mais interno.

 4. QUEM SÃO OS NOMES?  Liste os identificadores.
                        Onde cada um está definido?

 5. ONDE ELA TRABALHA?  Dispositivo, servidor, ou os dois?
                        (Capítulo 4)

 6. DIGA EM UMA FRASE   Se você não consegue,
                        o problema é da fórmula.
```

---

**Lembretes do locale pt-BR:** `;` separa argumentos, `;;` encadeia ações e termina cada fórmula nomeada, `,` é a vírgula decimal. Conectivos por extenso: `And`, `Or`, `Not`.
